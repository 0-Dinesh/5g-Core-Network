# Open5GS Network Slicing Lab

## Overview

This repository contains practical implementations of 5G Core Network concepts using Open5GS. The work includes installation, configuration, network slicing, subscriber provisioning, throughput analysis, and future laboratory exercises.

The objective is to understand the architecture and operation of a virtualized 5G Core Network through hands-on experimentation.
